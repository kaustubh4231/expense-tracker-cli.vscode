# 💰 Expense Tracker

A simple command-line Expense Tracker made with Python. I built this project while learning Python to practice the concepts I've learned so far and see how they work together in a real project.

## 📌 Features

* Add new expenses
* View all saved expenses
* Calculate total expenses
* Search for a specific expense
* Save expenses in a text file
* Simple menu-based interface

## 🛠️ Python Concepts Used

* Variables and data types
* User input and type casting
* `if`, `elif`, and `else`
* `while` and `for` loops
* Strings and string methods
* String indexing
* File handling
* Reading and writing files
* Type conversion
* Flag variables

## 📂 Project Structure

expense-tracker/

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Clone this repository or download the project.
3. Open the project folder in VS Code.
4. Run `expense_tracker.py`.
5. Choose an option from the menu and follow the instructions.

## 🖥️ Example

```text
*** Expense Tracker ***

1. Add Expenses
2. View Expenses
3. Calculate Total
4. Search Expenses
5. Exit

Enter your choice:
```

The expenses are saved in `expenses.txt`, so they are still available when the program is run again.
